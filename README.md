# KELIN — концепт редизайна

Концепт редизайна страницы [«Юрист по строительным спорам»](https://kelinlaw.ru/sfery-biznesa/yurist-po-stroitelnym-sporam/).

`index.html` — один самодостаточный адаптивный файл: только векторная графика, нейтральная палитра с фирменным синим для акцентов, текстовая колонка ~65 знаков.
Кнопка «Показать пометки» в правом нижнем углу показывает, что изменено в каждом блоке.

Картинки с текущего сайта (логотип, иллюстрация первого экрана, логотипы клиентов, фото руководителей) встроены в `index.html`, исходники лежат в `assets/`.
Десктопная сетка широкая, как `.container` на сайте (до 1684 px).
